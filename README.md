## 📌 Sobre a GM Tecnologia

A **GM Tecnologia** é uma parceira estratégica para empresas que buscam modernização, resiliência e inovação através da tecnologia. Combinamos sólida experiência em infraestrutura, nuvem e desenvolvimento de soluções digitais:

- 💻 **Desenvolvimento de Soluções Sob Medida**: Criação de sistemas web, portais corporativos, integrações de APIs e automação inteligente de processos repetitivos.
- ☁️ **Computação em Nuvem & Modernização**: Migração e gestão de ambientes corporativos em nuvem, garantindo mobilidade, escalabilidade e redução de custos operacionais.
- 🛡️ **Segurança da Informação & Conectividade**: Blindagem perimetral, interligação segura entre unidades de negócio e políticas ativas de proteção contra ameaças digitais.
- 💾 **Continuidade de Negócios & Resiliência**: Estratégias preventivas de Disaster Recovery, backups imutáveis e garantia de alta disponibilidade sem interrupções.
- 📊 **Observabilidade Proativa & Governança de TI**: Monitoramento 24/7 de ativos tecnológicos e suporte estruturado com SLAs ágeis.
- 🚀 **Publicação Segura de Aplicações**: Hospedagem de alta performance com certificados criptografados e proteção contra ataques web (WAF).

## ⚡ Otimizações Implementadas no Projeto

- **📱 Menu Mobile Responsivo**: Drawer moderno com transições fluidas e botão de alternância acessível (`aria-expanded`, controle por teclado).
- **🧭 ScrollSpy Inteligente**: Identificação automática da seção visível na tela e destaque em tempo real no menu superior.
- **📋 Copiar E-mail com Feedback Visual**: Botão de cópia rápida com notificação flutuante (*toast*) para agilizar o contato comercial.
- **💬 Atendimento Flutuante (WhatsApp)**: Botão de ação rápida integrado com mensagem direta personalizada.
- **🔍 SEO & Open Graph Completo**: Meta tags otimizadas para mecanismos de busca, cards sociais (LinkedIn, WhatsApp, Twitter) e favicon vetorial em SVG.
- **🚀 Performance & Acessibilidade**: Tipografia corporativa *Plus Jakarta Sans* com `preconnect`, ícones Lucide vetorizados e conformidade semântica.
- **🧹 Limpeza e Padronização do Repositório**: Remoção de arquivos legados desnecessários, inclusão de `.gitignore` e estruturação modular (`style.css` e `main.js`).

## 🚀 Como Executar Localmente

Como o projeto é construído em tecnologias web puras e leves (HTML5, Tailwind CSS, JavaScript), basta:

1. Clonar o repositório:
   ```bash
   git clone https://github.com/GustavoMS0/GmTecnologia.git
   ```
2. Entrar na pasta do projeto:
   ```bash
   cd GmTecnologia
   ```
3. Abrir o arquivo `index.html` em qualquer navegador ou utilizar a extensão **Live Server** no VS Code.
